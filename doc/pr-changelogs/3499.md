### Caveats
 * `Spring.GetTimer`, `Spring.GetTimerMicros` and `Spring.GetFrameTimer` now return opaque userdata instead of lightuserdata, and `Spring.DiffTimers` only accepts those handles. This prevents leaking engine heap addresses through `Spring.DiffTimers`. Pass timers straight back to `Spring.DiffTimers` rather than treating them as numbers. Reversed timer order now raises an error.
