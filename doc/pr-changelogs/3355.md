* added `Spring.GetCommandsTargeting(unitID, cmdIDs[, queued])`, returning the command tags per unit of the given command types that target the unit (front orders only unless `queued`)
* added the synced full-control callouts `Spring.ClearCommandsTargeting(unitID, cmdIDs)`, which removes those commands from every unit's queue the way `CMD.REMOVE` does (including the orders factories pass on to new units), and `Spring.ClearTargetingFromUnit(unitID)`, which drops current unit and weapon targets on the unit without touching command queues or its neutral state
