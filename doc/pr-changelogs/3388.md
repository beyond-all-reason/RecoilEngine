### Gunship-like landing for fixed-wing planes
 * added a possibility for fixed-wing airplanes to have gunship-like aka "agile" movement (precise landing, more lenient turning) at take-off, landing, and short distance flight. Unit def `agileFlight`, boolean, default false.
 * added the callin `UnitFlightRegimeChanged(unitID, unitDefID, unitTeam, "agile"|"cruise")`, called for "agile" aircraft when the mode switches after take-off or before landing. "cruise" is the existing flight mode.
 * add `agileSpeed` unit def tag, the speed in elmo/s above/below which an agile aircraft changes the flight regime. Defaults to 0.4x of normal speed.
 * add `agileTurnRate` unit def tag, the turnrate for agile movement in TA angular units. Unlike regular turnrate it scales down with current movement speed. Defaults to 270 in TA angular units (this is about 45°/s).
 * add `agileAccRate` unit def tag, in elmo/frame², for both acceleration and deceleration in agile movement. Defaults to regular acceleration (`maxAcc`).
 * add `agileAltitude` unit def tag, in elmos. Defaults to normal `cruiseAltitude`.
 * add `cruiseDistance` unit def tag, in elmos. If the move goal distance is below this, an agile air unit will never enter regular "cruise" movement.
 * add `agileLandOnly` unit def tag, boolean, default false. The agile movement is then used only while the idle mode of the aircraft is "land"; set to "fly" it moves like any other fixed-wing plane.
 * add `cruiseEntryAngle` (degrees, default 30), `cruiseEntrySpeed` (share of `agileSpeed`, default 0.6) and `cruiseEntryTurnBoost` (`agileTurnRate` multiplier while heading for a cruise leg, default 3) unit def tags: they set how readily agile movement hands back to "cruise".
 * an agile aircraft in "cruise" no longer brakes for a goal it can not stop on from where it is: it flies past, comes round at speed and brakes on that pass (at most two passes per goal).
 * add all of the above to Lua `UnitDefs`.
 * add all of the above to `Spring.GetUnitMoveTypeData` and `Spring.MoveCtrl.SetAirMoveTypeData`.
 * the current mode can be inspected via `Spring.GetUnitMoveTypeData` under the "flightRegime" key ("agile" or "cruise").
