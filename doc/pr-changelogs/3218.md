* fixed `CMDTYPE_ICON_MODE` commands (fire state, move state, repeat, ...) showing an arbitrary unit's mode on the command card when the selection disagrees. The descriptor now reports the lowest mode present, which is at least stable between rebuilds of the same selection.
* `Spring.GetActiveCmdDescs` now returns a second value, an array keyed like the first, holding the sorted modes the selection actually has for each `CMDTYPE_ICON_MODE` command. More than one entry means the selected units disagree.
