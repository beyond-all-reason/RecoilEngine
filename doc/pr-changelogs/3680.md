 * fix `gl.ReadPixels` returning 4 values per pixel for `GL_RG`; it now returns 2.
 * add `GL.RED` and `GL.RG` for the `format` argument of `gl.ReadPixels`.
 * add the base pixel-format names (`GL.RGBA`, `GL.RGB`, `GL.ALPHA`, ...) and type the `gl.ReadPixels` formats and results (from #3314 by sparr).
 * `gl.CreateTexture` treats `format = GL.RGBA` and `format = GL.ALPHA` as `GL.RGBA8`, so games that passed them while the names were `nil` keep the same texture; with `DeprecatedGLWarnLevel` set it warns that `GL.RGBA8` should be used.
