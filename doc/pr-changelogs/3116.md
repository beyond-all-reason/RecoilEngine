### Bindable unit select and command
* unit select and command are regular bindable actions now, `mouseprimary` and `mousesecondary`, bound to `Any+mouse1` and `Any+mouse3` by default. Games can move them to any button or key. `mouseprimary` also confirms a picked-up command (placing a build, targeting a dgun) and `mousesecondary` cancels one.
