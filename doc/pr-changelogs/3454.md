## Synced target lifecycle callins

- Add `UnitPreDelete(unitID, unitDefID, unitTeam)` for full-read synced clients.
  The unit remains readable; new orders, targets, dependencies and mutations
  involving it are rejected during finalization.
- Keep native death notifications in their original destructor position, after
  derived teardown. Native queues have not necessarily advanced in the callin.
  This corrects the earlier prototype's timing without passing invalid unit IDs.
- Add `UnitAttackTargetRemoved` after native neutral-target cleanup. Returned
  command tags are erased without advancing the successor.

Implementation and automated validation assisted by OpenAI Codex; human review
and gameplay verification are pending.
