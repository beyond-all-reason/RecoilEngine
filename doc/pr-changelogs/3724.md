### Features
 * added `wupget:GameLoaded()` callin. Called once when a game finishes loading from a native save (`.ssf`). Note that this does NOT run for old style Lua saves, which still use `wupget:GameStart`, plus `wupget:Load(data)` in unsynced.

### Caveats
 * a game loaded from a `.ssf` save now starts paused at the saved frame, announced like any pause (the `GamePaused` callin fires). To resume at once as before, call `Spring.SendCommands("pause 0")` from `GameLoaded`.
