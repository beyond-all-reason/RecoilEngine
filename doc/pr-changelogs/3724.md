### Features
 * added `wupget:GameLoaded()` callin. Called once when a game loaded from a `.ssf` save is ready, in place of `GameStart`.

### Caveats
 * a game loaded from a `.ssf` save now starts paused at the saved frame, announced like any pause (the `GamePaused` callin fires). To resume at once as before, call `Spring.SendCommands("pause 0")` from `GameLoaded`.
