 * Added the unit tag `agileLandOnly` (also a `MoveCtrl.SetAirMoveTypeData` member, reported by `Spring.GetUnitMoveTypeData`, default false): an aircraft with `agileFlight` uses the agile regime only while its idle mode is "land"; set to "fly" it behaves like a stock aircraft. An aircraft that loses agile flight while in the agile regime goes back up through the stock takeoff state.
