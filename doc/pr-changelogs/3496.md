### Fixes
 * `gl.CreateQuery` handles are now garbage-collected userdata that own their GL query, fixing a use-after-free when a handle was collected while still referenced by the engine, and double deletion corrupting an unrelated live query.

### Caveats
 * `gl.CreateQuery` returns an opaque userdata instead of lightuserdata; retain the handle and pass it back to the other `gl.*Query` functions. Deleting or reading the currently running query now raises an error.
