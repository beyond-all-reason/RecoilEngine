* added `--background-window` command-line switch for unattended runs that need rendering (tests, CI, replays, capture): the window opens without focus and behind other windows, never goes fullscreen, never minimizes or maximizes itself and is not replaced by a Windows "Not Responding" ghost window.
* added `Spring.IsBackgroundWindow()`.
* `Spring.WarpMouse` no longer moves the system pointer while the window has no focus and the pointer is not over it (alt-tabbed out); the engine still takes the new position.
* with `--background-window`, `Spring.SetWindowMinimized` and `Spring.SetWindowMaximized` do nothing and return `false`.
