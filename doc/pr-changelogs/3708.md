* added `--background-window` command-line switch for unattended runs that need rendering (tests, CI, replays, capture): the window opens without focus and behind other windows, never goes fullscreen, never minimizes or maximizes itself, is not replaced by a Windows "Not Responding" ghost window, and mouse warps do not move the system pointer while it has no focus.
* added `Spring.IsBackgroundWindow()`.
* with `--background-window`, `Spring.SetWindowMinimized` and `Spring.SetWindowMaximized` do nothing and return `false`.
