### Caveats
* the `__newindex` metamethod now receives `nil` and `NaN` keys, e.g. `foo[nil] = bar`, rather than raising an error first.

### Internals relevant for engine devs
* Lua: Ported the Lua 5.4.3 nil table assignment rules. Before this change, clearing keys inside a `pairs` loop could corrupt iteration or raise "invalid key to 'next'". After, a nil value never inserts a key so cannot grow or rehash a table. A table with `__newindex` is searched for the key before calling the metamethod, and nil/NaN keys are passed to that call instead of raising "table index is nil" or "table index is NaN" before they can be handled. Accordingly, handling them now may be required.
