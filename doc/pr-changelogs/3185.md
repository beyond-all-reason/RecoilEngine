 * added `sensors.requireSonarUnderWaterForProjectiles` modrule, defaults to `sensors.requireSonarUnderWater`. If true, non-allied projectiles and particles that are underwater are only drawn when also in sonar, the same as units. This includes hardcoded particles such as geothermal smoke, so set it to false to keep the old behaviour.
 * added `requireSonarUnderWater` weapondef (default false). Weapon projectiles stay visible underwater unless this is set; only relevant when the `sensors.requireSonarUnderWaterForProjectiles` modrule is true.
