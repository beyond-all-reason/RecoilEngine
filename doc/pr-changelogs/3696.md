Lua:
 * Added `system.allowPreGameCommands` modrule (default `false`), exposed as `Game.allowPreGameCommands`, to allow LuaUI `Spring.GiveOrder*` calls before GameStart.
 * Added optional `skipUnitStats` argument to `Spring.CreateUnit` (default `false`) to exclude temporary units from team unit-count statistics without affecting live unit counts or lifecycle callins.
 * Added `Spring.SetUnitCommandDrawStart(unitID, drawStart)` to hide the unit-to-first-command line while retaining command icons and the rest of the queue.
