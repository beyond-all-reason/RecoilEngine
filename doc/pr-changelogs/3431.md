### Misc

* Add synced `Spring.RegisterCommand(cmdID, { movement = true })` to register global custom command properties. `movement` defaults to false and enables movement lookahead, including attack completion and aircraft decisions. Registrations belong to the synced Lua environment and are removed when it is destroyed, including on reload. Duplicate IDs are errors. Unrecognized entries and values of the wrong type are ignored. `Engine.minCustomCmdID` exposes the lowest registrable ID.
