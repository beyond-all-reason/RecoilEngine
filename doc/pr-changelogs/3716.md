 * `LoadingMT = 2`: the load screen (LuaIntro) draws in its own GL context at display rate for the whole load, independently of the loading thread, e.g. for a video or an animation. LuaIntro gets no events from the load (e.g. `GamePreload`) and LuaMenu is not updated until the load is done. Falls back to `LoadingMT = 1` if the second context can not be created.
 * `LoadingMT = 1`: the load screen gets a frame in whenever the loading thread is outside a locked section (it froze for seconds at a time before), and VSync is suspended for the load, which no longer takes longer with VSync on.
