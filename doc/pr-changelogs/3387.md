 * Added the unit tag `terrainLookahead` (seconds, default 0 = off; also a `MoveCtrl.SetAirMoveTypeData` member, reported by `Spring.GetUnitMoveTypeData`): strafing aircraft hold altitude against the highest ground along that much of their flight path ahead, so they climb for cliffs before reaching them and leave plateaus in a descent instead of a dive. `terrainLookaheadDescent` (share of `altitudeRate`, in (0, 1], default 0.5) sets how fast that reference comes down again.
