* added `wupget:UnitCommandAdded(unitID, unitDefID, unitTeam, cmdID, cmdParams, cmdOpts, cmdTag,
  queueType)` callin. Fires for every insertion into a unit's command queue with no exceptions.
* added `wupget:UnitCommandRemoved(unitID, unitDefID, unitTeam, cmdID, cmdParams, cmdOpts, cmdTag,
  queueType)` callin. Fires for every removal from a unit's command queue with no exceptions.
* both of the above callins are raised within the queue as it is being modified so do not support
  issuing new orders within the event; this reenters engine code in an unsafe way.
* added `CMD.QUEUETYPE_ORDER`, `CMD.QUEUETYPE_RALLY` and `CMD.QUEUETYPE_BUILD` constants.
