 * `Spring.SetMapShader(standardID, deferredID, combinedShader, shadowShaderID)` gains an optional fourth argument: a program that draws the ground into the shadow map, so a map shader that discards ground can stop it casting shadows there too.
 * new callin `DrawGroundPreShadow`, sent before that draw (for uniforms and textures); also sent with `AlwaysSendDrawGroundEvents`. Its entry in `Script.GetCallInList()` tells that the fourth argument exists too.
