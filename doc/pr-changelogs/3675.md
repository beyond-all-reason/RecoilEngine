### Caveats
 * `Spring.GetUnitSelfDTime` now returns seconds (it returned half seconds). Check `Engine.FeatureSupport.selfDTimeInSeconds`.
 * the engine no longer prints the "self-destruct in Ns" countdown to the console; games show it themselves.

### Misc
 * the self-destruct countdown runs per frame instead of per slow update, so it is exact and a `selfDestructCountdown` of `0` goes off at the next unit update instead of the next slow update. It still waits while the unit is stunned.
 * `selfDestructCountdown` in unit defs can be fractional seconds.
 * added `Spring.SetUnitSelfDTime(unitID, seconds?) → nil`, starts or restarts a unit's self-destruct countdown with any number of seconds; `nil` cancels it. Works on units whose def has `canSelfD = false`.
 * added `UnitSelfDestructStarted(unitID, unitDefID, unitTeam, remainingSeconds)` and `UnitSelfDestructCancelled(unitID, unitDefID, unitTeam, remainingSeconds)` callins.
