### Caveats
 * `Spring.GetUnitSelfDTime` now returns seconds (it returned half seconds), and `nil` for a unit that is not counting down. Check `Engine.FeatureSupport.selfDTimeInSeconds`.
 * a unit def with a negative `selfDestructCountdown` is now rejected: the engine logs an error and does not load that unit def.
 * the engine no longer prints the "self-destruct in Ns" countdown to the console; games show it themselves.

### Misc
 * the self-destruct countdown runs per frame instead of per slow update, so it is exact and a `selfDestructCountdown` of `0` goes off at the next unit update instead of the next slow update. It still waits while the unit is stunned.
 * `selfDestructCountdown` in unit defs can be fractional seconds.
 * added `Spring.SetUnitSelfDTime(unitID, seconds?) → nil`, starts or restarts a unit's self-destruct countdown with any number of seconds; `0` self-destructs the unit during the call unless it is stunned, `nil` cancels. Works on units whose def has `canSelfD = false`.
 * added `UnitSelfDestructStarted(unitID, unitDefID, unitTeam, remainingSeconds)` and `UnitSelfDestructCancelled(unitID, unitDefID, unitTeam, remainingSeconds)` callins. Restarting a running countdown sends `UnitSelfDestructStarted` again.
