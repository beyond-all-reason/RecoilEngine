### Lua GL queries
 * added `GL.SAMPLES_PASSED`, `GL.ANY_SAMPLES_PASSED`, `GL.ANY_SAMPLES_PASSED_CONSERVATIVE`, `GL.PRIMITIVES_GENERATED`, `GL.TIME_ELAPSED`, `GL.TIMESTAMP` constants.
 * `gl.CreateQuery(target)` now takes an optional query target, one of the above (the default is `GL.SAMPLES_PASSED` which is the previous behaviour). Timer targets return `nil` when the driver does not support it (OpenGL 3.3 or later; or supports `ARB_timer_query`).
 * `gl.RunQuery(query, func, ...)` runs the query with the target it was created with. `GL.TIME_ELAPSED` queries measure the GPU time of the draw calls issued inside `func` in nanoseconds.
 * added `gl.QueryCounter(query)`: records a `GL.TIMESTAMP` into a timestamp query (the difference of two is the GPU time between them, and these can be nested freely).
 * added `gl.GetQueryDelta(startQuery, endQuery, blocking)`: the GPU nanoseconds between two timestamp queries, subtracted as 64-bit values (raw timestamps do not fit Lua's single precision numbers).
 * `gl.GetQuery(query, blocking)`: add a new `blocking` argument (default `true`), makes the function return `nil` instead of stalling when the result is not available yet, so a widget can read last frame's queries without a GPU sync. Results are read as 64-bit values where supported.
 * GL query functions now reject anything that is not a query from `gl.CreateQuery` with a Lua error; a deleted query is ignored (`gl.GetQuery` returns `nil`).
 * `gl.GetQuery` returns 0, not garbage, for a query that never ran, and raises an error when asked for the query `gl.RunQuery` is measuring. Deleting that query inside `gl.RunQuery` is allowed; it is freed when the run ends.
 * fixed `gl.CreateQuery` queries being garbage collected while the engine still used them. Queries are now Lua-owned userdata: the garbage collector deletes a query nothing references, and `gl.DeleteQuery` deletes it at once (calling it twice does nothing).

### Tracy and profiling
 * Tracy builds now record GPU zones (OpenGL timer queries). Every `SCOPED_GL_DEBUGGROUP` in the engine's draw code is also a GPU zone, and `gl.PushDebugGroup`/`gl.PopDebugGroup` from Lua open and close a GPU zone of the same name, so Lua draw passes annotated for graphics debuggers show their GPU time in Tracy too.
 * Tracy builds now also plot video memory use: the texture, buffer and renderbuffer memory the engine and Lua allocated (`VRAM: textures`, `VRAM: buffers`, `VRAM: renderbuffers`, sizes estimated from formats and dimensions; every GL object is also listed under these pool names in Tracy's memory view), the memory in use on the whole GPU as the driver reports it (`VRAM: driver used`) with NVIDIA's eviction counters, and on Windows this process's video memory usage and budget as the OS reports them (`VRAM: process usage`, `VRAM: process budget`).
 * built-in frame profiler now reports frame timing on OpenGL 3.3 drivers that do not list `ARB_timer_query` (timer queries are core in 3.3)
