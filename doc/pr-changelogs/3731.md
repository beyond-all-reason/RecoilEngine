 * `Update(dt, presentedDt)` and `Spring.GetLastUpdateSeconds()` gain a second value, `dt` as shown on screen: with vsync on, whole display periods; otherwise equal to `dt`. It replaces `Spring.GetPresentedUpdateSeconds()`. The base widget and gadget handlers pass both on (base gadgets now get `dt` too); a game's own handler has to pass the second one on itself.
 * `CamFrameTimeCorrection` 2 takes the raw frame time when frame times stay between whole display periods.
