 * `Update(dt, presentedDt)` and `Spring.GetLastUpdateSeconds()` gain a second value, `dt` as shown on screen: with vsync on, whole display periods; otherwise equal to `dt`. For example, on a 100 Hz monitor regular `dt` can be, say, 0.009 or 0.011, while `presentedDt` is consistently 0.01 in normal circumstances but reverts to `dt` when there's lagspikes etc. The base widget and gadget handlers pass both on (base gadgets now get `dt` too); a game's own handler has to pass the second one on itself.
 * `CamFrameTimeCorrection` 2 takes the raw frame time when frame times stay between whole display periods.
