### Caveats
 * removed the `AutoAddBuiltUnitsToFactoryGroup` and `AutoAddBuiltUnitsToSelectedGroup` springsettings. Neither has had any effect since 2019. To put units built by a factory into the factory's group, call `Spring.SetUnitGroup` from the `UnitFromFactory` callin.

### Springsettings that apply without a restart
These springsettings now take effect when changed mid-game. Feature support tag: `Engine.FeatureSupport.liveConfigChanges`, a number (currently 1) that goes up when more settings become live.
 * network and catch-up: `MinSimDrawBalance`, `MinDrawFPS`, `UseNetMessageSmoothingBuffer`, `DumpGameStateOnDesync`, `NetworkTimeout`, `InitialNetworkTimeout`, `ReconnectTimeout` and the `Link*` bandwidth limits. `NetworkLossFactor` still only applies to the next connection.
 * sound: `snd_device`, while SDL plays the sound (`UseSDLAudio`, the default).
 * input and camera: `DoubleClickTime`, `CrossSize`, `CrossAlpha`, `CrossMoveScale`, all `RotOverhead*` and `CamFree*` keys, `CamSpringEnabled`, `UseDistToGroundForIcons`.
 * UI and rendering: `TeamHighlight`, `SelectThroughGround`, `BuildIconsFirst`, `MiniMapRefreshRate`, `MiniMapMarker`, `GroundLODScaleReflection`, `GroundLODScaleRefraction`, `GroundLODScaleTerrainReflection`, `UnitTransparency`, `TeamNanoSpray`, `MinimizeOnFocusLoss`.
 * `/GroundDecals 1` mid-game re-adds the building plates of standing units and features. Scars, tracks and Lua decals of the old handler are still dropped.

### Fixes
 * fix `snd_device` being ignored with SDL output (`UseSDLAudio`, the default). `Spring.GetSoundDevices` and the infolog device list gave OpenAL names, which SDL rejects; they now give SDL names, and a saved name with the OpenAL prefix is converted.
